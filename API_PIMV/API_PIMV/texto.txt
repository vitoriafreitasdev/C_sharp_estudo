
Site para planejamento, divulgação, realização e acompanhamento de eventos acadêmicos
em Tecnologia da Informação.

estrutura 

tabelas: 
usuarios e eventos

controller do usuário precisa ter:

	pegar todos usuarios

	pegar usuario pelo id

	cadastro

	login

	usuarios podem curtir e comentar em eventos postados

	chat para comunicação entre usuários 

controller do evento precisa ter:

	pegar todos eventos 

	pegar evento pelo id

	editar => passar o id do evento e do usuario que criou

	deletar => passar o id do evento e do usuario que criou

	emissão de certificado 

	Adicionar eventos

controller do site
	
	inscrição ao evento

	pegar eventos criados por um usuario especifico

	mostrar comentarios 

	adicionar comentarios 

	

usuario precisa ter:
	
	id,
	nome,
	email,
	idade,
	senha

evento precisa ter:

	id,
	titulo, 
	data,
	descrição,
	tipo de evento (hackathons, jornadas,  semanas de curso, congressos
	estudantis, competições de programação e mostras de projetos)
	keyParaEmissaoDoCertificado,
	users_inscritos,
	idDoUsuarioQueCriou
